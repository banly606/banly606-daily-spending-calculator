# 日均花费计算器

一个纯前端的小工具，用来计算手机、电脑等贵重物品平均到每天的花费。

核心公式：**日均花费 = 购买价格 ÷ 使用天数**（使用天数 = 截止日期 − 购买日期，截止日期留空则默认今天，不足 1 天按 1 天计）。

## 功能

- 添加 / 编辑 / 删除物品记录（名称、类别、价格、购买日期、可选截止日期）
- 每条记录显示日均花费、总价、已用天数
- 横向条形图对比各物品的日均花费
- 浅色 / 深色模式跟随系统自动切换
- 记录保存在浏览器本地（localStorage），支持导出 / 导入 JSON 备份
- 手机优先的响应式布局

## 本地使用

直接用浏览器打开 `index.html` 即可使用（数据保存在当前浏览器中）。

## 部署到 GitHub Pages

1. 把这三个文件（`index.html`、`style.css`、`app.js`）推送到一个 GitHub 仓库。
2. 在仓库的 **Settings → Pages** 中，将 Source 设为 `Deploy from a branch`，分支选择 `main`，目录选 `/ (root)`。
3. 保存后等待一两分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问，手机上也可以收藏使用。

## 数据说明

- 数据只存在当前浏览器的 localStorage 中，不会上传到任何服务器。
- 换设备或清理浏览器数据前，建议先在「数据管理」中导出备份，之后可随时导入恢复。
- 导入备份会**覆盖**当前所有记录，导入前会弹出确认。
